# Curso de muestra: front-principiante

Generado con prompts v2.

**Perfil del estudiante:**

- Nivel: Nunca he programado
- Experiencia: uso redes sociales y hago presentaciones; nunca he programado
- Objetivo: Desarrollo front-end
- Lenguaje: javascript

---

## Temario

1. **Guardar y nombrar datos: variables y valores** — Crear variables en JavaScript para guardar números y texto, distinguir tipos básicos y ver sus valores en la consola del navegador; primer paso para mantener contenido que luego mostrarás en la página. (_conceptos: valor literal, variable, asignación, tipo de dato (número / texto), console.log_)
2. **Haz que la página responda: salida y entrada (DOM básico)** — Seleccionar y modificar elementos HTML desde JavaScript y leer el valor de un campo; crear un botón que al clic muestre el texto del campo en la página (resultado visible en el navegador). (_conceptos: DOM (Documento), seleccionar elemento (querySelector), propiedad innerText / value, evento click (addEventListener)_)
3. **Elegir qué mostrar: condicionales que cambian la interfaz** — Usar if / else para decidir qué contenido mostrar según la entrada del usuario (por ejemplo, mostrar un aviso distinto si el campo está vacío), reutilizando selección de DOM e impresión en pantalla. (_conceptos: if / else, comparaciones (==, ===, !=, !==), booleano (true / false), bloque de código_)
4. **Repetir tareas: bucles para crear listas y elementos** — Generar elementos repetidos en la página usando bucles (for); por ejemplo renderizar una lista de mensajes a partir de datos, combinando DOM y condicionales previos. (_conceptos: for, iteración, índice (i), crear y añadir elementos al DOM (createElement / appendChild)_)
5. **Estructurar contenido: arrays y objetos para tus posts** — Almacenar múltiples entradas como arrays de objetos (autor, texto, fecha) y recorrerlos para renderizarlos dinámicamente en la página; mantener y actualizar la colección de posts. (_conceptos: array, objeto (propiedades y valores), acceder por índice, métodos básicos de array (push, length)_)
6. **Funciones: piezas reutilizables para la interfaz** — Crear funciones que reciban datos (p. ej. un objeto post) y dibujen componentes en la página; así evitarás repetir código y facilitarás cambios futuros. (_conceptos: función (declaración), parámetros, valor de retorno, reutilización / abstracción_)
7. **Integración y depuración: juntar todo y resolver errores** — Combinar variables, DOM, condicionales, bucles, arrays y funciones en una rutina coherente; usar console.log y mensajes en pantalla para localizar y corregir errores comunes (campo vacío, índice fuera de rango). (_conceptos: flujo de datos (estado), depuración básica (console.log), manejo de errores simples, pruebas manuales en el navegador_)
8. **Proyecto final: microblog interactivo en el navegador** — Construir una mini-aplicación front-end: formulario para crear posts, validación básica, almacenarlos en un array y renderizar la lista actualizada; tendrás una página funcional que puedes adaptar a un portafolio. (_conceptos: formulario y eventos, renderizado dinámico, actualizar colecciones en la UI, separación de responsabilidades (añadir vs renderizar)_)
